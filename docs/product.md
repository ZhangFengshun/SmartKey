# 产品范围

SmartKey是Android通用AI沟通输入法，适用于聊天、工作、邮件和其它编辑框。用户选择模型和提示词，决定是否发送。

当前能力：离线拼音；19人设、11类开场白、12关系润色；三候选自动填入/切换；键盘内3图OCR与分析；自动模型目录；加密配置/手动记忆；主题及本地试用。

回复面板打开自动导入当前剪贴板，不累积剪贴板历史。对方消息与宿主草稿分开；删除/清空操作草稿并保留消息来源。生成后自动填入，在草稿改变或编辑器切换时拒绝覆盖。发送始终由用户点击。

润色读取当前草稿，选定关系后保留原意改写。开场白通过主题生成。截图先本地识别并预览；分析不写入聊天，用户选择回复人设才生成回复。

不包含会员、购买、云端账号、自动发消息、后台聊天采集。语音、九宫格、端侧模型和跨平台列入后续评估，不宣称已完成。模型服务调用权限及额度由用户配置服务决定。
