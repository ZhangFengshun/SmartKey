# 键盘功能范围

| 功能 | 当前实现 |
|---|---|
| 帮你回 | 19个同名目录人设，三列滚动；独立提示词 |
| 草稿操作 | 删除/安全清空宿主草稿，消息来源保留，显式发送 |
| 候选 | 三个完整候选；首条自动填入，切换替换本次草稿 |
| 超会说 | 读取宿主草稿；12种关系；安全整稿/选区替换 |
| Hi | 11类开场主题，独立面板 |
| 读懂TA | 键盘内最多3图有序选择，本地OCR预览与模型分析 |
| 更多 | 输入法切换、人设管理、主题、自定义提示词；无付费入口 |
| 输入 | 离线全拼、英文、数字、14类符号 |
| 偏好 | 本地亲密度与主题，手动联系人记忆 |

分析结果只展示，不能当作回复自动提交。提示词与系统Emoji是独立实现；未取得其它产品隐藏服务，不能声称像素/云端生成行为完全一致。未实现语音、九宫格或账号体系。
