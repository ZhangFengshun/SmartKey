# 生成延迟

当前优化包括：已验证DeepSeek V4服务关闭隐藏思考；共享OkHttp连接池；取消时终止网络等待，避免旧请求占满生成线程。未修改用户的模型选择或密钥。

开发基准在同一模型上交替请求普通/快速模式。最近两组均值约4.83秒/2.89秒；实际键盘示例约2.92秒。样本有限、网络与服务排队波动较大，不能推断所有请求均有同样改善。

GenerationLatencyInstrumentedTest默认跳过。显式开启latencyBenchmark=true才调用用户配置服务，使用合成消息并只记录耗时和字符/token数量，不记录凭证、文本或推理内容。

取消阻塞测试使用不响应的本地服务器，验证线程能够及时退出；专用请求参数测试确保不发送到未验证模型或接口。
